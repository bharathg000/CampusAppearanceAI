# Campus Appearance Rules

## ID Card
- ID card must be worn around the neck.

## Shirt
- Normal/formal-looking shirt.
- Shirt must be tucked in.

## Trousers
- Formal trousers are required.

## Shoes
- Formal shoes are required.
- Any shoe colour is allowed.

## Hair
- Long hair is not allowed.
- Hair must be properly groomed.
- Single/full hair colour is allowed.
- Double/multi-coloured hair is not allowed.

## Beard
- Beard must be properly groomed.
- Long or messy beard is not allowed.
